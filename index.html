跟著飛行一起開飛機
50題互動搶答測驗

根據《跟著飛行員一起開飛機》撮要：由飛行前準備 → 引擎啟動 → 起飛 → 爬升 → 巡航 → 下降進場 → 降落 → 緊急狀況，對照波音 B777 與空中巴士 A330 解說。

適合課堂搶答、自學溫習、小組比賽。答完即出詳解，最尾有完整答案總覽。

核心知識撮要 · 8 張卡

第1章 飛行前準備

  • 簡報先確認天候，起降要迎風以縮短滑行距離
  • 飛行計畫要兼顧安全、舒適、效率（省油）
  • 燃料不只到目的地，還要替代機場＋待機＋滑行＋補正燃料
  • 最大酬載量 = 最大零燃料重量 − 航運重量，約佔最大起飛重量 20%

第2章 引擎啟動

  • 出發前1小時集合，約40分鐘簡報與檢查
  • IRS 先開，需約10分鐘地面靜止校準才能設 FMS
  • FMS = 飛行管理系統，管航線、性能、燃油
  • 逃生要在90秒內完成，逃生滑梯10秒內膨脹

第3章 起飛

  • V1 = 決定起飛速度（超過必須繼續飛）
  • VR = 仰轉速度，V2 = 起飛安全速度（單引擎亦可爬升）
  • 起飛放襟翼增升力；起飛推力離地後轉爬升推力
  • TO/GA = 起飛／重飛推力

第4章 爬升

  • 高度表要 Transition / Set / Crosscheck
  • FL370 = 37000呎標準氣壓高度
  • Fly-by-wire = 線傳飛控，以電子訊號代替機械連桿
  • B777 用傳統操縱桿，A330 用側置操縱桿；自動駕駛是起飛後達一定高度才接通

第5章 巡航

  • 長程用階段式上升巡航（燒油變輕可爬更高更省油）
  • ECON = 經濟巡航速度降成本；馬赫數 = 飛機速度／音速
  • 搖晃主因是亂流、積雨雲、噴射氣流
  • 要不斷確認剩餘燃料

第6章 下降與進場

  • T/D = Top of Descent 開始下降點
  • 下降有怠速省油下降與固定航徑下降兩種概念
  • QNH = 修正海平面氣壓；三倍法則：高度差(千呎)×3 = 距離(海里)
  • 空中待機 = 盤旋等待降落許可

第7章 降落

  • ILS = 儀表降落系統，提供航向＋下滑道
  • 放襟翼增升力降進場速度；Gear Down = 放下起落架
  • VREF = 著陸基準速度；Flare = 著陸前平飄拉平柔和觸地
  • Go Around = 放棄降落重飛；自動降落需配合 ILS＋機場設備

第8章 緊急狀況

  • RTO = 在 V1 前放棄起飛
  • ETOPS180 = 雙引擎單發下180分鐘內可到合適機場
  • 太平洋單發故障要飄降轉飛最近合適機場
  • 黑盒子是橙色，含 FDR＋CVR；TCAS 在接近碰撞風險時發警告與避撞指示
